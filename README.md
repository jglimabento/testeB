# Cypress Practice Repository

A learning repository with introductory Cypress examples for browser interaction and API requests.

## Current exercises

- Browser login flow against the ServeRest demo application
- API login request and response assertion

## Stack

- Cypress 13
- JavaScript
- REST API testing with `cy.request()`

## Run

```bash
npm install
npm run cy:open
npm run cy:run
```

These are practice exercises against public demo services, not production-ready authentication tests. The repository is retained as a learning archive and is not one of the primary portfolio projects.
